# Безопасность и приватность

Текущее состояние безопасности и приватности.

## Секреты
- Хранятся в переменных окружения (`TELEGRAM_BOT_TOKEN`, `OPENROUTER_API_KEY`).
- `.env` не коммитится в репозиторий.

## Данные пользователей
- История диалога хранится в памяти процесса и теряется при перезапуске.
- Логи содержат техническую информацию (включая `user_id` и длину сообщений); содержимое ответов может логироваться длиной.

## Внешние сервисы
- OpenRouter получает текущее сообщение и контекст, формируемый приложением.

## Рекомендации для запуска
- Проверяйте, что секреты не попадают в логи и репозиторий.
- Храните файлы с ролями (`prompts/*`) без чувствительных данных.
