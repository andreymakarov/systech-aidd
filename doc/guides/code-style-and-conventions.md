# Code Style и договоренности

Краткие правила, применяемые в проекте.

## Ruff
- Длина строки: 100.
- Наборы правил: E, W, F, I, N, UP, B, C4, SIM.
- Авто-форматирование: `ruff format`.

## MyPy
- Режим: strict.
- Ключевые опции: `disallow_untyped_defs = true`, `no_implicit_optional = true` и др.

## Проектные соглашения
- 1 класс = 1 файл.
- SOLID, DRY, KISS.
- Типизация всех публичных функций и методов.

## Команды
- `make format` — форматирование + автофикс.
- `make lint` — линтер и типизация.
