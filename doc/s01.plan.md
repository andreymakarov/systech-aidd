# S01: Персистентное хранение (SQLite + async ORM + Alembic, KISS)

## Принципы
- БД: SQLite (файл)
- ORM: SQLAlchemy 2.x (async) + драйвер `aiosqlite`
- Миграции: Alembic (`render_as_batch=True` для SQLite)
- Политика данных: soft delete (`deleted_at`), метаданные `created_at` (ISO8601), `length`
- Конвенции: async I/O, DI через конструктор, 1 класс = 1 файл, KISS

## ER-схема
- messages(id PK, user_id INT, role TEXT, content TEXT, length INT, created_at TEXT, deleted_at TEXT NULL)
- Индекс: (user_id, deleted_at)

## Изменения по файлам
- `pyproject.toml`: добавить `SQLAlchemy[asyncio]`, `aiosqlite`; dev: `alembic`
- `src/bot/config.py`: `db_path` (env `DB_PATH`, default `data/bot.db`)
- `src/bot/message.py`: модель ORM `Message`
- `migrations/`: `alembic.ini`, `env.py` (async engine, `DATABASE_URL`), ревизия `create_messages_table`
- `src/bot/conversation.py`: async ORM + DI (`async_sessionmaker[AsyncSession]`); методы `async`
- `src/bot/__main__.py`: создать папку БД; инициализировать `AsyncEngine`/`session_factory`; DI в `ConversationManager`
- `src/bot/handlers.py`: `await` методы менеджера; перед LLM оставлять только `{role, content}`

## Эскизы
```python
# message.py
class Message(Base):
    __tablename__ = "messages"
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    user_id: Mapped[int]
    role: Mapped[str] = mapped_column(String)
    content: Mapped[str] = mapped_column(Text)
    length: Mapped[int]
    created_at: Mapped[str]
    deleted_at: Mapped[str | None] = mapped_column(nullable=True)
```

```python
# conversation.py (API)
class ConversationManager:
    def __init__(self, session_factory: async_sessionmaker[AsyncSession]) -> None: ...
    async def get_history(self, user_id: int) -> list[dict[str, str | int]]: ...
    async def add_message(self, user_id: int, role: str, content: str) -> None: ...
    async def clear_history(self, user_id: int) -> None: ...
```

```python
# handlers.py (LLM подготовка)
history_db = await self.conversation_manager.get_history(user_id)
```

```python
# миграция (core)
op.create_table(
    "messages",
    sa.Column("id", sa.Integer, primary_key=True),
    sa.Column("user_id", sa.Integer, nullable=False),
    sa.Column("role", sa.String, nullable=False),
    sa.Column("content", sa.Text, nullable=False),
    sa.Column("length", sa.Integer, nullable=False),
    sa.Column("created_at", sa.String, nullable=False),
    sa.Column("deleted_at", sa.String, nullable=True),
)
op.create_index("ix_messages_user_deleted", "messages", ["user_id", "deleted_at"]) 
```
