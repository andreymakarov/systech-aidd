# Frontend Vision (FE)

Кратко: админский UI для статистики и ИИ-чата. Принципы: простота, доступность, отзывчивость, тёмная тема.

- Технологии: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui.
- Компоненты: базовые UI (Button, Card, Input, Label, Separator, Toast), ThemeToggle.
- Навигация: главная (dashboard в FE-S03), чат (FE-S04).
- Темизация: next-themes, класс dark, переменные цвета в globals.css.
- Тестирование: Vitest + RTL для компонентов и страниц.
