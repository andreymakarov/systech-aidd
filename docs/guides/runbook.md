# Эксплуатация и трейблшутинг

Краткие инструкции по запуску/остановке и диагностике.

## Запуск/остановка
```bash
make run
```
Остановка: `Ctrl+C`.

## Логи
- Уровень: INFO.
- Формат базовый, вывод в консоль.

## Типовые проблемы
- Отсутствуют обязательные переменные окружения → ошибка конфигурации при старте.
- Неверные токены Telegram/OpenRouter → ошибки в логах, отсутствуют ответы.
- Сетевая недоступность OpenRouter → ошибки LLM в логах.

## Действия
- Проверить `.env` и значения токенов.
- Перезапустить процесс после исправления настроек.
