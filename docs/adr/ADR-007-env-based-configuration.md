# ADR-007: Конфигурация через переменные окружения

## Статус

Принято (Accepted)

## Контекст

Необходимо выбрать способ конфигурации приложения. Основные подходы:
1. Переменные окружения (.env файл)
2. Конфигурационные файлы (JSON, YAML, TOML)
3. Аргументы командной строки
4. Конфигурационные классы с хардкодом

## Решение

Использовать **переменные окружения**, загружаемые из `.env` файла.

### Конфигурация

```bash
# .env
TELEGRAM_BOT_TOKEN=your_bot_token_here
OPENROUTER_API_KEY=your_api_key_here
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_MODEL=openai/gpt-4o-mini
SYSTEM_PROMPT=Ты - полезный AI-ассистент...
```

### Инструменты

- **python-dotenv** для загрузки `.env` файла
- Класс **Config** для валидации и доступа к настройкам
- `.env.example` как шаблон для быстрого старта

### Принципы

1. **Fail Fast** - валидация при старте приложения
2. **Явные обязательные параметры** - падаем, если не указаны
3. **Разумные значения по умолчанию** для необязательных параметров
4. **Типизация** через класс Config

## Последствия

### Положительные
- ✅ Стандартная практика (12-factor app)
- ✅ Безопасность (`.env` в `.gitignore`)
- ✅ Простота изменения без ребилда
- ✅ Разные конфигурации для разных окружений
- ✅ Простота использования (cp .env.example .env)
- ✅ Не коммитим секреты в git

### Отрицательные
- ⚠️ Нужно создавать `.env` файл перед запуском
- ⚠️ Нет валидации формата на уровне файла

### Обязательные параметры

- `TELEGRAM_BOT_TOKEN` - токен бота
- `OPENROUTER_API_KEY` - API ключ

При отсутствии приложение **падает с понятной ошибкой**.

### Параметры по умолчанию

- `OPENROUTER_BASE_URL` = `https://openrouter.ai/api/v1`
- `OPENROUTER_MODEL` = `openai/gpt-4o-mini`
- `SYSTEM_PROMPT` = универсальный промпт

### Безопасность

```gitignore
.env          # секреты - не коммитим
.env.example  # шаблон - коммитим
```

## Альтернативы

1. **YAML/JSON конфигурация** - отклонена (избыточна, секреты в репозитории)
2. **Аргументы командной строки** - отклонены (неудобно для множества параметров)
3. **Хардкод** - отклонен (небезопасно, негибко)
4. **Конфигурационный сервис** - отклонен (оверинжиниринг для MVP)
